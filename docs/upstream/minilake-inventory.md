## Cross-cutting findings

- **Global state:** route modules mutate module-level dictionaries and counters. The app registers module callbacks for optional snapshot and restore. There is no per-workspace or per-session state boundary in these route modules.
- **Persistence:** filesystem bytes, DuckDB-managed rows, module dictionaries, and ephemeral handles have different owners. A JSON snapshot stores selected dictionaries; it does not atomically commit table data and metadata.
- **Spark/job paths:** the default job executor starts a sibling Docker container using an Apache Spark image and invokes `spark-submit`. The job layer resolves secret templates for that environment. Unity Catalog's temporary credential paths support Spark's connector; its Delta SQL reader delegates to DuckDB. These paths conflict with BrickHouse's no-JVM execution contract and single authoritative table provider.
- **Route composition:** the app factory imports notebook support, DuckDB, global settings, persistence, all service registration, and Spark image prewarming. Including even a subset of route modules unchanged would pull Minilake ownership assumptions across BrickHouse boundaries.
- **Reuse safety:** request/response fields and workflow ordering are not implementation code. Translate them into BrickHouse-owned models/contracts and test both successful operations and explicit unsupported/error behavior.

## Required BrickHouse tests before equivalent claims

1. Catalog and schema identifiers, duplicate/missing objects, restart-stable IDs, and alias consistency through the authoritative catalog.
2. DBFS/Files byte round trips, chunked upload failure/retry, path traversal rejection, overwrite behavior, metadata, and DBFS/Files shared-storage visibility.
3. Job definition/run lifecycle through a fresh child process, parameter passing, timeout/cancellation/descendant cleanup, bounded/redacted output, idempotent submit, and restart reconciliation. No task may become successful merely because it was skipped.
4. Scoped secret ACL enforcement, worker-only resolution, invalid/missing secret errors, and log/result redaction.
5. Table mutation through the selected Delta provider, cross-interface reads, crash injection around commit/journal finalization, and recovery.
6. REST model/request behavior against exact pinned SDK/client versions and occasional sanitized personal-account reference observations. Local regression tests must not invoke Databricks.
