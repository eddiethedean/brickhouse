## Release interpretation

The capability states are not equivalent to broad Databricks compatibility. The 0.1.0
candidate has offline installed-wheel evidence only on macOS arm64 with CPython
3.11.15 and 3.12.13. Linux x86_64 remains unqualified pending CI.
No remote Databricks runtime, cloud compute,
or caller-authentication compatibility is claimed.
