## Restart, replay, and staged inputs

The POSIX crash matrix in
`tests/unit/test_delta_operation_journal.py::test_killed_writer_reconciles_each_delta_sqlite_boundary`
kills the writer before Delta dispatch, after the native Delta commit but
before SQLite finalization, and after SQLite finalization. Reopening the
workspace leaves an uncommitted intent uncertain; replay does not infer a
failed provider call or fabricate a table. When a matching Delta commit exists,
same-payload replay returns version 0 and row `42`, with exactly one history
entry. Reusing the recovered operation ID with a changed payload raises
`OperationKeyReuseError` and adds no commit.

The staged-input cleanup guard checks unresolved journal operations after
workspace restart. Cleanup is rejected while the pre-dispatch operation remains
uncertain and the staged file is still present. Cleanup succeeds after exact
commit reconciliation or an already-finalized commit. An in-process artifact
lock serializes ordinary `write_staged()` use with cleanup.

## Retention behavior

Worker attempt stdout/stderr now has a 24-hour retention window. A controlled
clock test expires the payload, keeps attempt/run/job history and terminal
status, and makes the Jobs output response include `logs_expired: true`. The
text fields are cleared once; truncation metadata and identity remain. Metadata
schema 20 adds the one-way expiry transition and upgrades schema 19 without
losing retained logs.

SQL statement result behavior remains the B011.4 contract: results expire
after 12 hours, result chunks and manifest are removed, and statement history
remains readable with `CLOSED` status. The controlled-clock regression also
checks result-chunk fetch failure after expiry.

Worker log expiry is lazy: a Jobs output retrieval sweeps eligible outputs, or
the repository's explicit `expire_attempt_outputs()` maintenance method can be
called. No background expiry scheduler is implemented. SQLite releases the
stored text from the row for page reuse; this does not promise that the metadata
file shrinks immediately.
