# B017.3 — Child notebook outcomes and cleanup

## Scope

This local conformance slice implements `dbutils.notebook.run()` and
`dbutils.notebook.exit()` inside notebook kernels. Child calls accept relative
`.ipynb` files or marked Databricks Python `.py` exports contained under the
selected notebook root. Each child runs in a fresh kernel and receives a copied
worker context with the call's ASCII string arguments overlaid on inherited
widget parameters. Child Python state and cell outputs stay isolated; the caller
receives only the child's string exit value. A child that completes without an
explicit exit returns an empty string.

`timeout_seconds=0` disables the child deadline; positive values use a monotonic
total deadline, including kernel startup and cell execution. The accepted range
is 0–86,400 seconds. `dbutils.notebook.exit()` stops later cells and returns a
UTF-8 string up to 1 MiB. Arguments are limited to 16 KiB of encoded JSON and
must contain ASCII string keys and values. Relative path resolution rejects
absolute paths, unsupported extensions, ambiguous extensionless paths, symlink
escapes and targets outside the selected root.

Child failures and timeouts propagate as typed notebook-run errors without
exposing a deleted temporary artifact path. The runner owns each kernel and its
process group. A child timeout and a parent-cell interruption both terminated
the child kernel and a process it had spawned. The parent notebook still writes
its own failure artifact. This evidence covers local kernel interruption;
compute-resource reset/termination coupling remains B017.5.

## Evidence

- **Environment:** BrickHouse 0.1.0.dev0; Python 3.11.14; macOS 26.5.2 arm64;
  Sparkless 4.14.1; ipykernel 7.4.0; jupyter-client 8.10.0; nbclient 0.11.0;
  nbformat 5.11.1.
- **Tests:** `env -u DATABRICKS_TOKEN -u DATABRICKS_HOST PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 /tmp/brickhouse-b0171-env/bin/python -m pytest -q tests/unit/test_notebook_runner.py tests/unit/test_notebook_source.py tests/unit/test_notebook_context.py tests/unit/test_dbutils_local.py`
- **Result:** 48 focused tests passed. Cases include separate `%run` and child execution scope, widget argument delivery, hidden child outputs, string return values, early exit, marked `.py` child execution, child failure/timeout propagation, total-timeout process cleanup, parent-interruption cleanup of kernel descendants, and all previous notebook profile/source cases. Ruff check/format, strict mypy, and `pip check` passed.
- No Databricks credentials/account, cloud compute, JVM, or Spark driver was used.

## Limits

This is a local relative-path subset, not workspace path resolution, remote notebook execution, SDK notebook task dispatch, or full Databricks job-parameter precedence. Child artifacts are temporary and are not exposed through `dbutils.notebook.run()`. Resetting or terminating attached classic compute during active notebook execution is left to B017.5. Trusted notebook code is not sandboxed.
