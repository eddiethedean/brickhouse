# B007.1 — Catalog, schema, and table identity persistence

Date: 2026-10-19

## Result

SQLite metadata schema 2 assigns persistent UUIDs to catalog and schema rows and enforces their immutability. Instance-scoped repositories read those namespace records and persist table registrations with stable table IDs, canonical locations, Delta format markers, and managed/external ownership. Managed locations reserve `tables/<table-id>` under the workspace root. External registrations accept local paths outside that root. Canonical path resolution makes symlink aliases collide with the existing location registration.

Existing metadata schema 1 opens read-only and upgrades to schema 2 on owner acquisition. The migration is transactional and runs under the POSIX workspace owner lock. The workspace format remains version 1. Reopen tests verify namespace and table IDs and registrations persist. CLI diagnostics now expose metadata schema version and partial local metadata repository status, while catalog HTTP APIs and table-provider operations remain planned.
