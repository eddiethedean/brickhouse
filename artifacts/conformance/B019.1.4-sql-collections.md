## Frozen local cases

[The fixture](../../tests/fixtures/sql/B019.1.4-collection-cases.json) reuses the four-row typed Delta input from [B019.1.1](../../tests/fixtures/sql/B019.1.1-orders-scalar-query.json). The query projects `order_id`, `item_ids`, and `details` through the local SQL service. The test compares the complete Arrow schema, including `list<int64>` and `struct<coupon:string,tags:list<string>>`, and exact rows. It preserves an empty list, a null list, null nested fields, and an entirely null struct as distinct values; no nested value is converted to JSON text.

In Sparkless 4.15.0, selecting `details.coupon` produced `SparklessError`/`unresolved_column`; array subscript syntax and `map(...)` also failed explicitly. The nested struct SQL-resolution gap was reported as [Sparkless issue #1715](https://github.com/eddiethedean/robin-sparkless/issues/1715). These errors were visible and were not replaced with fabricated values.
