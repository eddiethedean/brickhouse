Unknown-column SQL fails eagerly during query construction for both serverless and classic standard; the test does not claim deferred Spark Connect analysis.

The facade now blocks DataFrame cache/persist operations before they can leak state across sessions; previously these methods delegated to Sparkless. Classic standard/dedicated settings must be explicit. Serverless cannot select a classic runtime, and unsupported configuration keys are rejected in both serverless and classic contexts.

The SQL Connect profile `spark-connect-local-v1` is rejected before session creation. Connect protocol execution and reference-specific deferred analysis remain explicitly unsupported pending B036. Access-mode labels do not establish Databricks security or runtime parity.
