The assertion compares the complete Arrow result schema and values. It retains decimal values as `Decimal`, null amount on order 3, boolean null-detection results, `float64` arithmetic output, and the three active rows in the declared order. The fixture is checked into the repository; the test neither derives expected results at runtime nor loads `.env`.
