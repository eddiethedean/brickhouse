# B012.2.1 — Empty tables and schema mismatch

Date: 2026-10-21

## Result

Passed the selected local Sparkless/Delta boundary cases on Sparkless 4.15.0.

- A typed empty PyArrow table was written through Sparkless into a managed Delta table. Sparkless and delta-rs both read zero rows while retaining the `id: int64 not null, label: string nullable` schema at Delta version 0.
- An append with `id: string` against the existing `id: long` schema was rejected by the published Sparkless provider boundary as `SparklessError` with category `incompatible_table_schema`. The managed Delta version stayed at 0 and its original row remained unchanged.
- This records the exact public error exposed by Sparkless; the table service's internal `IncompatibleTableSchemaError` is encoded as a provider error category at that boundary.
