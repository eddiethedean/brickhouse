## Verified behavior

The pinned SDK executed actual local Sparkless SELECTs through simulated serverless, pro, and classic SQL warehouse identities. Each response contained rows from the same committed local Delta table, and each terminal request released its persistent warehouse admission lease.

SDK requests queued behind active per-warehouse and workspace-wide leases. FIFO promotion activated a queued statement; polling then dispatched it and released the lease. Filling the local one-active/two-workspace-wide/eight-queued admission policy returned a persisted `RESOURCE_EXHAUSTED` statement without dispatching its deliberately invalid SQL. Missing, stopped, and deleted warehouse IDs were rejected before a statement row or admission lease was created.

A test paused a real local SELECT after the Sparkless query had materialized its result. Stopping the warehouse invalidated its lease; the API returned `CANCELED` without exposing the result. The original Delta table version and rows remained unchanged. A restart reconciliation test marked a RUNNING request failed without replay and released its admission.

The pinned SQL kernel's B045 capture showed that its `/sql/1.0/warehouses/<id>` path becomes a `warehouse_id` field in `POST /api/2.0/sql/sessions`. BrickHouse now resolves that field against the same persisted warehouse records: a running known ID receives an explicit `501 UNSUPPORTED_OPERATION`, a missing ID receives `404`, and a stopped ID receives `409`. This binds identity and preserves a truthful unsupported response; it does not implement the SQL connector session lifecycle or prove connector execution. B021 retains that work.

## Limits

Warehouse allocation, profiles, sizing, lifecycle and admission are simulated/local policy, not Databricks execution or queue parity. Statement parameter binding, the pinned SDK's default hybrid wait behavior, timeout cancellation, explicit cancel, chunking and result expiry remain B011.3–B011.4 work. The API remains unauthenticated and does not establish remote SQL compatibility. The connector session route is intentionally unsupported until B021.
