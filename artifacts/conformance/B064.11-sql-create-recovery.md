# B064.11 — SQL CREATE recovery

**Date:** 2026-10-22  
**Status:** Passed focused local regression coverage; rechecked on Sparkless 4.15.1  
**Scope:** Recover interrupted managed SQL table creation through the shared journaled Delta service.

## Implementation

`CREATE TABLE` now inspects an existing registration before treating `IF NOT EXISTS` as a no-op. It returns no-op only for a supported managed Delta snapshot. A managed registration without a Delta log is removed safely and the CREATE is retried through the normal table service. A failed initial provider write triggers cleanup only after the service confirms there is no snapshot; the journal prevents cleanup when an operation remains unresolved. External registrations, malformed Delta logs, and unresolved provider operations fail explicitly and retain their state or data.
