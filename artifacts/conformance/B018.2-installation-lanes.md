# B018.2 — Base and notebook-extra installation lanes

**Status:** passed locally on 2026-10-21  
**Scope:** built `brickhouse==0.1.0.dev0` wheel installed in two fresh Python 3.11.15 virtual environments. Tests used the local SDK loopback fixture; no Databricks account or cloud compute was used.

The built base wheel declares these runtime dependencies:

- `sparkless==4.15.0`
- `deltalake==1.2.1`
- `pyarrow==23.0.1`
- `sqlglot==30.24.0`

The only project extra is `notebooks`, which declares `ipykernel==7.4.0`, `jupyter-client==8.10.0`, `nbclient==0.11.0`, and `nbformat==5.11.1`. The Databricks SDK and pytest were installed separately as local test-driver tools; neither is a BrickHouse base runtime dependency. The base environment reported all four notebook distributions absent. The notebook-extra environment reported all four exact pins present. Both environments passed `uv pip check`; `uv lock --check` passed, and `uv build` produced the source archive and wheel.

The test process ran with `DATABRICKS_TOKEN`, `DATABRICKS_HOST`, and `JAVA_HOME` unset and `PATH` limited to the base environment, where Java was not available. There were no notebook packages in this installed environment.
