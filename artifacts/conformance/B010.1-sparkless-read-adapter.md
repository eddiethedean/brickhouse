# B010.1 — Internal Sparkless session and snapshot adapter

Date: **2026-10-20**. Result: **passed for the read-only B010.1 contract**.

## Implementation

`brickhouse.engines.sparkless.SparklessSessionFactory` creates a fresh public Sparkless `SparkSession`, applies an explicit `spark35-local-v1` configuration, and attaches a session-owned external catalog provider. Each provider owns a fresh BrickHouse namespace state and resolves names through `DeltaRsTableService`; it returns a public `ExternalTableDescriptor` with the stable registered table ID, canonical local path, typed schema, and the exact current Delta version. Sparkless then reads that Delta version, so reads share the same table identity and committed data as the BrickHouse service.

The default explicit settings are ANSI enabled, case-sensitive resolution disabled, and UTC session timezone. Callers may override only those three settings. The tested schema envelope includes bigint, `decimal(12,2)`, nullable arrays, and nested nullable structs. Unsupported types, non-empty field metadata, and array/map element nullability that the Sparkless provider wire format cannot retain are rejected before a descriptor is returned.

This is an internal adapter. `Workspace.session()` is not exported; B010.2 adds selected named and registered-path writes through the same table service. SQL/job execution paths remain unconnected, and B010.3 retains concurrent session-state verification. The adapter does not claim Spark Connect or Databricks Runtime parity.
