# B013.1 — Python worker launch and bounded output

Date: 2026-10-19\
Task: B013.1\
BrickHouse version: `0.1.0.dev0`

## Implemented contract

`brickhouse.runtime.run_python_worker()` launches one script using an explicitly
resolved absolute interpreter path (defaulting to the current `sys.executable`) and
an explicitly resolved working directory. It uses an argument vector with no shell,
passes a per-attempt `WorkerContext` as canonical JSON in
`BRICKHOUSE_RUN_CONTEXT_JSON`, and starts from a minimal environment rather than
inheriting credentials, Python import paths, or session state. The context snapshots
JSON values at construction and is limited to 16 KiB.

Stdout and stderr are drained concurrently while retaining at most 1 MiB per stream
by default. Callers can select a limit from 0 through 64 MiB for each stream. The
result reports the actual exit code, retained text, truncation flags, configured
limits, and resolved interpreter/script/cwd. Output is not persisted to a workspace
log by this task.

## Validation

```text
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q tests/unit/test_worker.py
python -m ruff check src/brickhouse/runtime tests/unit/test_worker.py
python -m ruff format --check src/brickhouse/runtime tests/unit/test_worker.py
python -m mypy src/brickhouse/runtime
```

All passed. The worker tests ran real child interpreters and covered immutable
context snapshots, explicit cwd, bounded stdout/stderr, actual nonzero exit status,
credential/import-path non-inheritance, malformed/oversized context, invalid paths,
and invalid limits. No `.env`, Databricks account, network, JVM, or Spark process was
used.

## Limits

This is a low-level launch primitive, not a public job runner. CLI `run` remains
unavailable. Timeout, cancellation, descendant reaping, private service credentials,
job persistence, staging cleanup, and durable logs are future B013 slices. A child
that starts descendants holding inherited output pipes can delay completion until
those pipes close; B013.3 owns timeout and process-group cleanup.
