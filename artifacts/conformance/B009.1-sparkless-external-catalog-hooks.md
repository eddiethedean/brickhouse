## Contract implemented

The upstream change adds `ExternalCatalogProvider`, `ExternalTableDescriptor`, and
`ExternalTableFormat` to Sparkless' engine-neutral Rust API. The Polars session can
resolve an external identifier to a native Delta snapshot for `SparkSession.table()`,
`DataFrameReader.table()`, and SQL relation reads. It checks the declared schema,
surfaces provider errors, avoids resolving a missing multipart name to an unrelated
local table, and keeps the provider isolated from `new_session()` while sharing it
across clones. The core trait has an explicit unsupported default for backends that
do not implement the hook. The API and its limitations are documented in upstream
`docs/EXTERNAL_CATALOGS.md`.

## Availability and limits

PR #1692 is open and unmerged. The hook is not part of published Sparkless 4.13.4;
consumers need a compatible source revision or later release. This implementation
provides synchronous Rust lookup and local Delta reads only. It does not provide
catalog persistence, delegated writes, Python callbacks, asynchronous/network
transport, or BrickHouse integration. Nullability is not compared because the
current Polars schema adapter does not retain Delta nullability metadata.
