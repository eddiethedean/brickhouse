# B014.5 — Serverless and classic execution-context resolution

Date: 2026-10-20

## Result

Implemented the internal pre-dispatch resolver for the bounded serverless and classic task shapes. It returns immutable context values with run identity, profile, selected environment/runtime, settings, resource identity/generation, task arguments, timeout and retry metadata. It does not dispatch work or claim profile compatibility with a Databricks workspace.

Serverless maps environment version `1` to the active local Python minor version and accepts only exact installed `deltalake==1.2.1` and `pyarrow==23.0.1` dependency pins. It applies ANSI and UTC defaults, requires `disable_auto_optimization=true`, and rejects unprovisioned clients, versions, dependencies, installs, compute objects, unsupported task fields and non-standard performance targets. Classic resolution accepts inline, declared shared/new, or existing all-purpose compute using the B014.4 runtime/access contract and carries the selected identity and generation. All-purpose terminated clusters resolve with `autostart=true` while preserving the resource's terminated state until dispatch.

Both task shapes require a normalized absolute `/Workspace/...` path. The resolver rejects URI/Git paths, traversal and non-canonical paths; file existence and upload are B014.2. It rejects SQL warehouse notebook tasks and credential-shaped task parameters. Explicit timeout zero and omitted timeout resolve to no timeout; positive values are bounded by the local worker's 24-hour maximum. Standard `ALL_SUCCESS` conditions are accepted; other conditions remain unsupported. Alternate retries and dispatch are not implemented here.

Capability C058 is `partial`; C053–C056 remain `planned`. No runtime capability or real workload behavior was promoted.
