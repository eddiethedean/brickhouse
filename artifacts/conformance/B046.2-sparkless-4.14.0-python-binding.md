## Limits

These checks establish the selected released hook contract, not a production BrickHouse adapter. The later [B046.3 probe](B046.3-sparkless-4.14.0-provider.md) found nullable-struct bugs #1694/#1695 that these 56 cases do not cover; their passing result does not clear the complete typed integration gate. Sessions remain owner-thread objects; separate-session/thread and process-interruption checks are owned by B046.3. Callback writes buffer full IPC data; error wrapping does not preserve arbitrary original Python service exception subclasses. There is no async callback cancellation interface. [The API inventory](../../docs/upstream/sparkless-4.14.0-python-provider.md) records these limits. B010 must preserve the table-service authority and reject unsupported write bypasses.

No Java/Spark source build, Databricks account request, `.env` read or upstream modification was used.
