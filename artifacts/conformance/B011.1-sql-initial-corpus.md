The tests initialize temporary workspaces and commit real local Delta snapshots. No `.env`, Databricks token, remote workspace, JVM, or Spark process is used.

## Verified behavior

- SQLGlot parses one Databricks-dialect statement at a time. The planner classifies it, resolves table references through the current namespace, rewrites accepted references to canonical registered identifiers, and returns a plan before executing effects.
- SELECT projection, predicates, `COUNT`, `SUM`, grouping, and one inner equijoin execute through a fresh, isolated Sparkless session. Table aliases are resolved in the AST before rendering the query for Sparkless.
- `CREATE SCHEMA` and `DROP SCHEMA` route through `CatalogService`.
- `CREATE TABLE ... USING DELTA` with the selected primitive schema and `CREATE TABLE ... USING DELTA AS SELECT` write through `DeltaRsTableService`. `DROP TABLE` uses its ownership-aware removal path. A fresh Sparkless session reads CTAS output from the same registered table.
- `IF NOT EXISTS` is a no-op for an existing target; duplicate DDL returns the catalog's typed duplicate error.
- Multiple statements, unregistered tables, path/table functions, anonymous SQL functions, parameters, sampling, CTEs, nested queries, self-joins, unsupported joins, and non-Delta DDL are rejected before a DDL target is created. A Sparkless execution failure propagates and is not retried on another engine.

## Scope limits

This is parser/binder and execution evidence for the exact local versions above, not Databricks compatibility evidence. Supported SQL types and operators remain limited to the selected schema and query profile. SQL parameters, CTEs, nested queries, table-valued functions, path-based relations, outer/self joins, mutations, `CREATE/DROP CATALOG`, statement REST lifecycle, warehouse lifecycle/admission, cancellation, and bounded result transport are not implemented by B011.1. Those behaviors remain assigned to later B011/B019/B021 work. SQLGlot is used for parsing and AST handling; it does not provide execution semantics.
